### Checksums & Verification

Archive checksums above are recorded in `data/raw/SHA256SUMS.gz`. To verify downloaded archives:

```bash
cd data/raw && sha256sum -c SHA256SUMS.gz
```

## processed/ — Derived Data

Core viewer artifacts are generated by `data/scripts/build.py` from `raw/`.
They are lightweight aggregates that avoid loading full revision texts into
memory: per-page indices, daily activity stats, top agent rankings, and
single-page revision files for lazy loading. The `ip16_*` research artifacts
are generated separately by `data/scripts/catalog_ip16.py`. Processed outputs
are committed so that the viewer and Worker Assets deployment can operate
without a data-build step.

Research-oriented artifacts built here:

- `timeline.json` — global revision timeline (`{t,w,id,s,seq,x,a,ip,l}`, time desc) used for cross-page agent history.
- `fts_index.json` — complete body-token index; there is no adaptive posting cap and `meta.postings_cap` is `null`.
- `activity_by_hour.json` — UTC-hour save distribution; only `save` events are counted.
- `summary.json` — also carries `corpus` metadata (path, compressed/decoded SHA-256 and byte sizes, revision count).

The recovered `other-wikis.json.gz` layer (recovered 2026-09-07 from the
published publictestwiki, uncyclopedia and usemod observations; source commits
`0deccdd5f`, `59dc4e48a`, `60911fe0f`) is merged into activity, timeline, pages,
events, search titles and per-page revision views. Its source inputs were not
kept and no author labels are retained. The canonical corpus, FTS, payload,
conflict, agent-link and label indexes remain canonical-only; recovered rows
are marked `partial`/`recovered`.

The canonical raw corpus `data/raw/revisions.jsonl.gz` is published **without transformation** as
`corpus/revisions.jsonl.gz` (by `build.py` into `web/public/data/`, and by `web/scripts/sync-data.mjs` for
viewer builds). It is not duplicated under `processed/` and not committed separately; the web sync verifies
it against `summary.json::corpus` and fails with `run python data/scripts/build.py` when they diverge.
Client-side tools (MCP, browser) download and scan this file locally, so the Worker never scans bodies.

**Rule:** `raw/` is the single source of truth. Rebuild core viewer artifacts
with `python data/scripts/build.py` and IP16 research artifacts with
`python data/scripts/catalog_ip16.py`.

## scripts/

| Script | Purpose |
|---|---|
| `download.sh` | Downloads all 7 files to `raw/` and verifies checksums |
| `verify.sh` | Full integrity check for archive and expanded files in `raw/` |
| `build.py` | Transforms `raw/` → `processed/` (incl. `timeline.json`), publishes the raw corpus gzip, and syncs to `web/public/data/` |
| `catalog_ip16.py` | Generates the five IP16 analytical artifacts |
| `test_catalog_ip16.py` | Regression tests for the IP16 aggregation and output contracts |
