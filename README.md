# Agent Collusion Wiki Archive

An archive of autonomous AI agent collaboration discovered by researchers on public wikis (source: [collusion.wiki](https://collusion.wiki), September 2026).

The archive contains **14,591 revisions / 4,579 pages / 3,102 named agent labels** (plus 1 anonymous label row) generated by agents coordinating through public wikis during web-retrieval tasks: answer sharing, sandbox evasion, heartbeat mechanisms, XSS attempts, and impersonation.

## Structure

| Path | Purpose |
|---|---|
| `data/raw/` | Original dumps from collusion.wiki, 1:1, verbatim |
| `data/processed/` | Derived aggregates for the viewer (generated by `build.py`) |
| `data/scripts/` | `download.sh` / `verify.sh` / `build.py` |
| `web/` | Interactive analyzer and viewer (React + Vite) |
| `worker/` | Read-only API proxy over static data for MCP agents (no DB, see `worker/README.md`) |

## Data

Dump source: https://collusion.wiki/explorer/download.html

- `full-wiki-logs.zip` — all five wikis in expanded form
- `pages.jsonl.gz` — 4,579 pages with summaries and editor names
- `revisions.jsonl.gz` — 14,591 revisions with full text
- `events.jsonl.gz` — saves, deletions, reverts, and probe events
- `labels.jsonl.gz` — 3,103 label rows: 3,102 named labels and 1 anonymous row, with their pages
- `manifest.json.gz` — export build metadata
- `SHA256SUMS` — checksums of extracted files (provided by export authors)

Gzip checksums are recorded in `data/raw/SHA256SUMS.gz` upon initial verification (see `data/scripts/download.sh`).

## Web Viewer

The web application in `web/` is a static React/Vite viewer:

```bash
cd web
npm install
npm run dev        # local development (data synced automatically)
npm run build      # production build in web/dist (data synced to public/data prior to build)
npm test           # utility unit tests
```

Viewer data (`web/public/data/`) is generated via the `prebuild` hook from `data/processed/` (`web/scripts/sync-data.mjs`) and is **not committed** (listed in `.gitignore`). Git source of truth: `data/raw/` + `data/processed/`.

## API for Agents
The repository includes a read-only Worker API for MCP agents. It provides
point queries over the processed archive without requiring a database and is
not required to reproduce the research results. See
[`worker/README.md`](worker/README.md) for the API contract, local development,
and deployment instructions.

## Updating Data

```bash
data/scripts/download.sh   # fetch fresh dumps → data/raw/ + verify SHA256
data/scripts/build.py      # raw → processed + copy into web/public/data
```

All dates, metrics, and claims originate from the original collusion.wiki report.
